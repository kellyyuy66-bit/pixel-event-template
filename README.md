# 像素风大会网页 · 模板仓库

把「人工智能创新协会 · 2026 全体大会」这个网页逆向拆解后，整理成的一套**可复用模板**。
下次办活动（迎新、年会、社团见面会、部门发布会……），只需要改 `content/` 里的几个 JSON、跑一条命令，
就能生成一个同样风格、可以独立运行的网页。

---

## 1. 三步上手

```bash
# ① 改内容：先改 content/00-event.json 的日期，再按需改其它 JSON
# ② 生成网页：
python build.py
# ③ 打开看效果：
#   双击 dist/index.html 即可（手机/电脑浏览器都行，不联网也能看）
```

换一届活动、日期变了？只改 `content/00-event.json` 一个字段：

```bash
python build.py --date 2027-09-20     # 也可以命令行临时覆盖，不动文件
```

封面信息条、结语落款、副标题、`Lv.` 等级、启动页徽标里的年份和日期会一起跟着变。

> `dist/index.html` 是**自包含单文件**：样式、像素字体、会徽全部内联。
> 拷到 U 盘、发给别人、丢到静态服务器上，都能直接打开。

```

├─ content/          ★ 全站内容（改这里就够了）

│  ├─ 02-ui.json       各页面标题、按钮、提示语
│  ├─ 03-lawn.json     封面小人台词
│  ├─ 04-stages.json   大会流程的 8 个环节与详情
│  ├─ 05-games.json    猜成语 / 逛三园 / 反向指令题库
│  └─ README.md      ★ 每个字段什么意思，看这里
├─ template.html     页面骨架 + 交互引擎（样式和内容都是外链，正常不用动）
├─ assets/
│  ├─ style.css      全站样式（8 百多行，想调视觉来这里）
│  ├─ zpix.woff2     像素中文字体

│  └─ logo-src.png   会徽原图（白底，留给 prep_logo.py 用）
├─ build.py          构建脚本：合并 content/*.json + 内联样式字体会徽 → dist/index.html
├─ prep_logo.py      可选工具：换会徽时用它裁白边 + 做圆形透明底
├─ docs/             使用说明
│  ├─ 01-网页功能说明.md
│  ├─ 02-生成提示词.md
│  ├─ 03-内容修改指南.md
│  └─ 04-交互增强说明.md
├─ .gitignore        忽略 dist/、__pycache__、系统与编辑器临时文件
└─ dist/
   └─ index.html     构建产物（拿去发布的就是这个，不入库）
```

## 3. 这个网页里有什么

| 页面 | 内容 |
| --- | --- |
| 启动页 | 像素进度条 + 载入日志，自动进入封面 |
| 封面 | 像素城市 + 草地小人（**可拖动、点一下会说话**）+ START 按钮 |
| 大会流程 | 8 张环节卡片，进度条与「已完成」状态自动保存 |
| 环节详情 | 弹窗展示环节介绍、要点、时长等信息 |
| 才艺展示 | 节目列表 + 每位同学一个独立整页 |
| 协会介绍 | 独立整页：理念、聚焦领域、部门 |
| 趣味游戏 | 4 个小游戏（猜成语 / 心口不一 / 逛三园 / 反向指令），带可放大的现场演示区 |
| 结语页 | 「谢谢观看」+ 完成度统计 + 重开按钮 |

键盘：`Enter` 开始/确认 · `Esc` 返回 · `← →` 切换 · `M` 音效 · `R` 重置进度。
详见 [docs/01-网页功能说明.md](docs/01-网页功能说明.md)。

## 4. 想改点什么

| 想做的事 | 去哪里改 |
| --- | --- |
| **改日期 / 场地 / 主办单位** | `content/00-event.json`（全站文案自动跟着变） |
| 改协会名 / 大会名 | `content/01-meta.json` → `meta` |
| 改环节（增删改流程） | `content/04-stages.json` → `stages` |
| 改才艺展示的同学 | `content/04-stages.json` → `fullPage:true` 那一项的 `gallery` |
| 改游戏玩法 | `content/04-stages.json` → `gamePage:true` 那一项的 `games` |
| 改猜成语题库 / 逛三园 / 指令表 | `content/05-games.json` |
| 改封面小人的台词 | `content/03-lawn.json` |
| 改界面按钮、提示语 | `content/02-ui.json` |
| 换会徽 / 换字体 | 替换 `assets/` 里的文件，跑 `prep_logo.py`（会徽）+ `build.py` |
| 调视觉风格（配色、字体大小、动效） | `assets/style.css` |
| 改交互逻辑、动画 | `template.html` 里的脚本段（进阶） |

字段级别的说明全在 [content/README.md](content/README.md)，照着填就行。

## 5. 常见问题

**改完打开是白屏 / 文字乱码？**
JSON 写错了。运行 `python build.py`，它会直接报出**哪个文件、第几行第几列**出错；
最常见的原因是：多写了一个逗号、少了引号、用了中文引号、或者加了 `//` 注释（JSON 不支持注释）。

**改完 `content/` 里的东西，没重新构建就打开了 `dist/index.html`？**
`dist/index.html` 是构建产物，内容已经烤进去了，改 JSON 后必须重跑 `python build.py`。

**直接双击 `template.html` 为什么字体不对、会徽不显示？**
`template.html` 是"半成品"，字体和会徽还是占位符，内容配置也是空的，
必须跑 `python build.py` 生成 `dist/index.html` 才是完整效果。

**想部署到网上？**
把 `dist/index.html` 上传到任意静态托管（校园服务器、对象存储、GitHub Pages 等）即可，
它只有一个文件，也不需要后端。若要用 GitHub Pages 直接发布 `dist/` 目录，
把 `.gitignore` 里的 `dist/` 那一行删掉再提交。

**手机上看会不会错位？**
页面按窗口宽度自适应（画布会自动缩放、窄屏会减少小人数量），
竖屏、横屏都试过。若发现异常，把窗口拖窄再看一次即可复现。

## 6. 来源说明

- 原始版本：`源码/template.html` + `源码/build.py` + `源码/prep_logo.py`（单文件像素风交互页）。
- 本仓库在其基础上做了几件事：
  1. **内容全部外置**：从单文件 `content.js` 拆成 `content/*.json`，按块维护，改内容不必进代码里翻找；
  2. **样式外置**：`template.html` 里的 `<style>` 抽成 `assets/style.css`，视觉调整不再是 html 里的 800 行；
  3. **日期变量化**：日期、场地、主办单位集中到 `00-event.json`，文案里用 `{year}` `{date}` 占位，换年份只改一处；
  4. **构建脚本改为路径自适应**，整个文件夹拷到任何位置都能跑，并且能校验 JSON、提示未定义的占位符；
  5. **新增封面互动**：小人可用鼠标拖动、点击弹出语言气泡（见 [docs/04-交互增强说明.md](docs/04-交互增强说明.md)）。
