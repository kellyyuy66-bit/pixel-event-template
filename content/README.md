# content/ —— 页面内容（按块拆分的 JSON）

所有文字、环节、人物、题库都在这个目录里。改完运行 `python build.py`，
`build.py` 会按文件名顺序把这里的 JSON 合并成一份配置，内联进 `dist/index.html`。

| 文件 | 对应配置 | 里面放什么 |
| --- | --- | --- |
| `00-event.json` | `event` | 大会日期 / 时间 / 场地 / 主办单位（唯一推荐每年先改的文件） |
| `01-meta.json` | `meta`、`boot` | 浏览器标题、封面文案、HUD、启动画面的那段日志 |
| `02-ui.json` | `ui` | 各页面标题、按钮、提示语、Toast、快捷键表 |
| `03-lawn.json` | `lawn` | 封面小人的台词池 |
| `04-stages.json` | `stages` | 大会流程的 8 个环节（含协会介绍、才艺、游戏的详情） |
| `05-games.json` | `quiz`、`gardens`、`commands` | 猜成语题库、逛三园素材、反向指令表 |

新增文件也行：只要顶层键不重复，`build.py` 会自动合并；键名重复会直接报错并指出是哪两个文件。

---

## 1. 日期只改一处：`00-event.json`

```json
{
  "event": {
    "date": "2026-10-14",
    "time": "14:00",
    "venue": "主会场",
    "org": "黄河科技学院"
  }
}
```

`date` 支持 `2026-10-14`、`2026/10/14`、`2026.10.14`、`2026年10月14日` 四种写法。
改完这里，下面这些文案里的占位符会**在构建时自动替换**：

| 占位符 | 2026-10-14 时的结果 | 用在哪 |
| --- | --- | --- |
| `{year}` | `2026` | 标题、封面副标题、Lv. 等级、启动页徽标 |
| `{month}` / `{day}` | `10` / `14` | 需要单独用到月、日的时候 |
| `{date}` | `2026.10.14` | 封面信息条、结语页落款 |
| `{dateIso}` | `2026-10-14` | 写成 ISO 格式的地方 |
| `{dateCn}` | `2026年10月14日` | 中文行文里 |
| `{weekday}` | `周三` | 自动按真实日历算 |
| `{time}` / `{venue}` / `{org}` | `14:00` / `主会场` / `黄河科技学院` | 任意文案 |

在 `event` 里再加一个字符串字段（例如 `"host": "校团委"`），就能在任意文案里用 `{host}`。

也可以不改文件、直接临时换日期：

```bash
python build.py --date 2027-09-20
```

> `{n}` `{num}` `{name}` `{done}` `{total}` 是页面运行时才替换的占位符，构建时原样保留，别手改。

## 2. `01-meta.json` —— 封面与启动页

`meta`：

| 字段 | 说明 |
| --- | --- |
| `htmlTitle` | 浏览器标签页 / 分享卡片标题，构建时也会同步写进 `<title>` |
| `eyebrow` | 封面最上面一行小字（字间用空格撑开） |
| `title` / `subtitle` | 封面主标题 / 副标题 |
| `meta` | 封面信息条，一行字，用 ` · ` 分隔 |
| `startBtn` / `startHint` | 开始按钮文字 / 按钮下方提示 |
| `hudName` / `hudLevel` | 左上角头像旁的名字 / 进度描述 |

`boot`：`title`、`badge`、`line1`（可写 `<b>`）、`line2`（`{n}` 是环节总数）、`logLines`（数组，逐行打印）。

---

## 3. `02-ui.json` —— 界面文案

按页面分组：`quests`（流程板）、`show`（才艺列表）、`perf`（个人页）、`about`（协会介绍）、
`games`（游戏列表）、`game`（单个游戏）、`end`（结语）、`modal`（环节弹窗）、`zoom`（放大展示）、
`help`（快捷键说明）、`toast`（右下角气泡）。

大部分是纯文字，改字面即可。`kicker` 里的 `{num}` 会自动换成环节编号。

---

## 4. `03-lawn.json` —— 封面小人台词

- `hint`：封面底部提示小字
- `lines`：通用台词池，点小人随机说一句
- `byAct`：给特定动作的小人配专属台词，键名可选
  `code` 敲代码 / `robot` 调机器人 / `badminton` 打羽毛球 / `drone` 遥控无人机 /
  `book` 看书 / `coffee` 喝奶茶 / `phone` 看手机 / `wave` 打招呼 / `talk` 聊天 / `walk` 走动

---

## 5. `04-stages.json` —— 大会环节

每个环节：

| 字段 | 说明 |
| --- | --- |
| `num` | 两位编号字符串，如 `"01"`，用于显示和「已完成」记录 |
| `icon` | 卡片图标：`bubble` `mic` `person` `snack` `note` `swords` `dice` `group` |
| `color` | 主题色，如 `"#9d90cf"` |
| `name` / `tag` | 环节名称 / 小标签 |
| `fig` | 详情页人物类型：`talk` `speak` `sing` `dance` `cup` `phone` `dice` `group` |
| `cloth` / `figCap` | 人物衣服颜色 / 人物下方小字 |
| `desc` | 一句话介绍 |
| `list` | 要点列表（字符串数组） |
| `chips` | 右下角信息块，`[["时长","约 8 分钟"], …]` |

特殊环节开关（每项最多用一个）：

| 开关 | 配套字段 | 效果 |
| --- | --- | --- |
| `aboutPage: true` | `about: { lead, body[], keys[], ideas[], fields[], depts[] }` | 打开「协会介绍」整页 |
| `fullPage: true` | `gallery: [{ name, role, kind, cloth, hair, desc, chips }]` | 打开「才艺展示」整页 |
| `gamePage: true` | `games: [{ id, name, sub, icon, desc, steps[], chips }]` | 打开「趣味游戏」整页 |

---

## 6. `05-games.json` —— 游戏题库

- `quiz`：`[{ "e": "🐔 ✈️ 🐕 🕺", "a": "鸡飞狗跳" }]`（表情提示 → 四字成语）
- `gardens`：`[{ "n": "动物园", "items": ["老虎", …] }]`
- `commands`：`[["举左手", "举右手"]]`（主持人的指令 → 正确动作）

---

## 7. JSON 语法（比 JS 严格，注意三条）

1. **不能写 `//` 注释** —— 说明就写在本文件里；
2. **最后一项后面不能有逗号**；
3. **字符串必须用英文双引号 `"`**，不能用单引号，也不能用中文引号 `“”`。

写错了不用慌，`build.py` 会直接告诉你哪个文件、第几行第几列出错。
