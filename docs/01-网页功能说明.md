# 01 · 网页功能说明

这份文档说明网页**由哪些页面组成、每页有什么、点哪里会发生什么**。
所有页面之间的跳转都是"同一页内切换画面"，没有真正的页面刷新，所以切换有淡入动效、也没有加载等待。

---

## 一、整体结构

页面是一个「全屏像素风 RPG 菜单」的隐喻：左上角是玩家状态栏（HUD），
中间是各个"画面"，底部是各种像素按钮。

```
启动页 ──自动──▶ 封面 ──START──▶ 大会流程（流程板）
                    ▲                  │
                    │                  ├─ 点环节卡片 ─▶ 环节详情弹窗
                    │                  ├─ 环节 05 ───▶ 才艺展示整页 ─▶ 单人整页
                    │                  ├─ 环节 01 ───▶ 协会介绍整页
                    │                  ├─ 环节 07 ───▶ 趣味游戏整页 ─▶ 单个游戏整页
                    │                  └─ 查看结语 ──▶ 结语页
                    └──────────────────────────────────┘
                              返回封面 / 返回流程
```

| 画面 ID | 名称 | 进入方式 |
| --- | --- | --- |
| `screen-boot` | 启动页 | 打开网页自动播放 |
| `screen-hero` | 封面 | 启动页结束后自动进入 |
| `screen-quests` | 大会流程（流程板） | 封面点 START / 按 Enter |
| — | 环节详情弹窗 | 点流程板上任意一张卡 |
| `screen-show` | 才艺展示 | 点环节 05 卡片 |
| `screen-perf` | 单人页 | 点才艺展示里的任意一位同学 |
| `screen-about` | 协会介绍 | 点环节 01 卡片 |
| `screen-games` | 趣味游戏 | 点环节 07 卡片 |
| `screen-game` | 单个游戏 | 点趣味游戏里的任意一个游戏 |
| `screen-end` | 结语页 | 流程板点「查看结语」 |

## 二、逐页说明

### 1. 左上角 HUD（所有画面都在）

- 像素头像 + 名字（`meta.hudName`）；
- 进度行：显示 `已完成 n/总数`，与流程板进度条同步；
- 三个工具按钮：
  - 喇叭：音效开关（也可按 `M`）；
  - 问号：打开「操作说明」弹窗（快捷键一览）；
  - 转圈：清空全部进度（也可按 `R`）。

### 2. 启动页 `screen-boot`

像素进度条从 0% 跑到 100%，同时滚动 4 行载入日志（日志文案在 `boot.logLines`），
跑完后自动切到封面并播放一段上行音效。**这是一段纯过场动画，1 秒左右就结束。**

### 3. 封面 `screen-hero`

- 底层：`#sceneCanvas` 画一整幅静态像素场景（天空渐变、远景天际线、中景建筑、中央学院大楼、树、灌木、栅栏、花、草坪、前景大树与花坛）。同一套随机种子，所以每次打开长得一样。
- 上层：`#cloudCanvas` 逐帧重绘，画**飘动的云**和**草坪上的像素小人**。
- 文案层：学校名、协会名、大会名、信息条、START 按钮、开始提示。
- **封面小人（本模板新增的互动）**：
  - 十几个小人在草地上各做各的事——敲代码、调机器人、打羽毛球、遥控无人机、看书、喝奶茶、看手机、打招呼、聊天，还有两个在最前排来回走动；
  - **用鼠标拖动任何一个站立的小人**，就能把他挪到别处（拖动时鼠标变成"抓取"手势）；
  - **用鼠标点一下小人**，他头顶会冒出一个像素语言气泡，随机说一句台词（台词在 `content.lawn` 里配）；
  - 气泡 3.4 秒后自动消失，期间如果继续拖那个人，气泡会跟着他一起移动。
  - 详见 [04-交互增强说明.md](04-交互增强说明.md)。

### 4. 大会流程 `screen-quests`（流程板）

- 顶部：`QUEST BOARD` 标题 + 「已完成 n/总数」和进度条；
- 中间：8 张环节卡片（编号、图标、名称、英文标签、主题色侧边条、完成状态）；
- 点击卡片 → 打开对应的详情弹窗或整页（环节 01/05/07 有专属整页）；
- 底部：「返回封面」「查看结语」两个按钮 + 一行说明小字。

### 5. 环节详情弹窗

- 头部：环节图标、编号（"环节 01"）、名称、英文标签；
- 左侧：像素人物立绘 + 下方小字说明；
- 右侧：一句话介绍、要点列表（带主题色圆点）、信息块（时长 / 形式等）；
- 底部：完成状态印章 + 「返回」+ 「标记完成 / 取消完成」；
- 键盘：`← →` 直接看上一个 / 下一个环节，`Enter` 切换完成状态，`Esc` 关闭。

### 6. 才艺展示 `screen-show`

- 节目卡片列表，每张卡显示序号、像素人物（唱歌 / 跳舞不同姿势）、姓名、形式；
- 点任意一位 → 进入**单人整页**；
- 底部「标记完成」会同时把环节 05 在流程板上标为已完成。

### 7. 单人页 `screen-perf`

一个节目一页：大号像素人物 + 姓名 + 形式 + 描述 + 信息块，
下面还有一排"其他同学"头像可以直接切换，底部有「上一位 / 返回才艺展示 / 下一位」。
键盘 `← →` 切换同学。

### 8. 协会介绍 `screen-about`

- 会徽 + 介绍文字（导语、两段正文）；
- 两组标签：「理念」和「招新」（招新那组是高亮样式）；
- 「聚焦领域」一排小方块；
- 「协会部门」一排部门卡片（图标 + 名称 + 关键词）。

### 9. 趣味游戏 `screen-games` / 单个游戏 `screen-game`

4 个游戏，每个都有**玩法说明**和**可交互的现场演示区**：

| 游戏 | 现场演示区怎么玩 |
| --- | --- |
| 猜成语 | 显示一组 emoji，点「揭晓答案」看谜底，可切上一题/下一题，下方小圆点记录已看过的题 |
| 心口不一 | 随机给一个"嘴上要说的数"，你点一个数字当"手指比出来的数"，相同就判失败 |
| 逛三园 | 点按钮抽一个园，给出园名和"里面有什么"的示例 |
| 反向指令 | 点按钮发一条指令，可揭晓"正确动作"（与指令相反） |

**演示区可以放大**：点演示区空白处（或聚焦后按 Enter），会打开一个大屏展示层，
里面的按钮依然可用——这是给投影仪/大屏用的。按 `Esc` 或点窗口外空白退出放大。

### 10. 结语页 `screen-end`

另一个场景：同一幅像素底图 + 飘落的粒子 + 「谢谢观看」+ 协会落款 + 完成度统计，
底部「返回流程」「重新开始」。

## 三、状态与持久化

- 进度存在浏览器 `localStorage`，键名 `ai2026.progress.v2`（在 `template.html` 里）；
- 每个环节以 `num` 为键记录完成状态，刷新/关掉重开都还在；
- HUD 的转圈按钮或结语页的「重新开始」可以清空；
- 音效开关**不做持久化**，每次打开都是开着的。

## 四、技术要点（给要改代码的人）

- **单文件自包含**：像素字体（Zpix，1MB 左右）和会徽都以 base64 内联进 `index.html`，
  所以最终产物约 1.2MB、但不依赖任何外部资源。字体/会徽的替换发生在 `build.py` 阶段。
- **像素字体**：正文全部使用 Zpix；`-webkit-font-smoothing:none` + `text-rendering:geometricPrecision`
  让字保持硬边，不被抗锯齿糊掉。
- **程序化像素画**：没有任何位图素材。图标是一张 16×16 的字符地图
  （`ICONS`，`o` 描边 / `b` 主体 / `a` 点缀）；人物立绘是 32×42 的代码绘制（`drawFigure`）；
  封面场景是 `drawScene` 用固定随机种子逐块 `fillRect` 拼出来的。
- **画布缩放策略**：`fitCanvas()` 按 `窗口宽度 / 560` 取整得到 2~4 倍缩放，
  画布逻辑尺寸随之变小，再用 CSS 放大回全屏，配合 `image-rendering:pixelated` 得到"大像素"效果。
  窗口尺寸变化时会重画（拖动小人留下的位置也会复位）。
- **音效**：`WebAudio` 现场合成的方波短音（`blip()` + `SFX`），没有音频文件。
  受浏览器策略限制，首次点击后才会有声音。
- **动画循环**：封面与结语各有一个 `requestAnimationFrame` 循环，
  离开对应画面时会 `cancelAnimationFrame`，不会在后台空跑。
