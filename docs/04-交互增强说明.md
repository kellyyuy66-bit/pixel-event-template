# 04 · 交互增强说明（封面小人的拖动与点击说话）

这次在逆向版本的基础上，给**封面草坪上的像素小人**加了两件事：

1. **用鼠标拖动任何站着的小人**，把他挪到草坪上的别处；
2. **用鼠标点一下小人**，他头顶冒出一个像素语言气泡，随机说一句台词。

两项都只作用于封面（`screen-hero`），不影响其它画面，也不改变原本的"走动小人"动画。

---

## 一、效果说明

| 操作 | 结果 |
| --- | --- |
| 鼠标移到站立的小人身上 | 光标变成"抓取"手势 |
| 按住拖动 | 光标变成"抓紧"手势，小人跟着走，气泡自动收起 |
| 松手 | 小人停在原地（原地不动，不会掉下去） |
| 单击（移动不超过 4 像素） | 头顶弹出语言气泡，随机一句台词 |
| 气泡显示期间继续拖这个人 | 气泡跟着他一起移动 |
| 气泡显示 3.4 秒 | 自动淡出 |
| 点一下正在来回走动的小人 | 同样会说话，但拖不动他（他会继续走） |
| 把小人拖到画布边缘 | 会被限制在画布范围内，不会拖丢 |
| 切换画面（比如进流程板再回来） | 气泡自动收起；小人位置在你刷新页面前保持 |
| 改变窗口大小 | 小人位置复位成默认排布（因为画布重新缩放了） |

## 二、台词怎么配 → `content/03-lawn.json` 的 `lawn`

```json
"lawn": {
  "hint": "拖动小人换个位置 · 点一下他会说话",
  "lines": [
    "欢迎来到人工智能创新协会！",
    "技术部了解一下？"
  ],
  "byAct": {
    "code": ["这段代码马上就跑通了……", "别说话，我在调 bug。"],
    "robot": ["参数再调小一点试试。"]
  }
}
```

- `lines`：所有小人共用的台词池；
- `byAct`：给特定动作配的"专属台词"——点那个动作的小人时，专属台词会和通用池一起参与随机；
- `hint`：封面底部那行操作提示，留空字符串则整条提示不显示。

动作键名与含义：

| 键名 | 小人在做什么 | 键名 | 小人在做什么 |
| --- | --- | --- | --- |
| `code` | 抱笔记本敲代码 | `book` | 低头看书 |
| `robot` | 抬手调小机器人 | `coffee` | 抿一口奶茶 |
| `badminton` | 举拍打羽毛球 | `phone` | 低头看手机 |
| `drone` | 遥控无人机 | `wave` | 抬手打招呼 |
| `talk` | 边说边比划 | `walk` | 来回走动 |

改完记得 `python build.py`。

## 三、实现原理（想自己改代码时看）

代码集中在 `template.html` 的 **第 4b 节「封面小人互动」**，以及 `drawLawn()` 里的小改动。

### 1. 命中检测：先让"画面"记住每个人在哪

`drawLawn()` 每帧都会重画草坪上的人。改造后有两点不同：

- 每个站立小人按其画布坐标推算出**一个矩形命中框**，压进全局数组 `heroPick`；
- 画之前会先查 `heroOff[序号]`，把用户拖出来的偏移量加上去。

```js
heroPick.push({ key:'s'+idx, idx:idx, act:st.acts[i],
                x0:px2-17*u2, x1:px2+17*u2, y0:py2-46*u2, y1:py2+2 });
```

`heroPick` 每帧重建，所以小人动、云在飘、窗口缩放，命中框永远是最新的。
鼠标位置通过 `getBoundingClientRect()` 换算成画布坐标（除以缩放倍数），
再**从后往前**遍历 `heroPick`——后画的（前排）优先命中，符合视觉直觉。

### 2. 拖动：只记偏移量，不改数据结构

拖动不修改任何布局数据，只往 `heroOff` 里写一个像素偏移：

```js
heroOff[序号] = { dx: ..., dy: ... };
```

好处是：草坪的排布逻辑（哪些人站在哪一排、按窗口宽度分几列）完全没动，
偏移量是纯粹的"覆盖层"；窗口尺寸变化时把 `heroOff` 清空就恢复默认排布。

拖动与否靠一个阈值区分——按下到松开，位移超过 `HERO_DRAG_T`（默认 4 像素）算拖动，
否则算点击。这样"想点一下却不小心抖了一下"也能正确出气泡。

### 3. 气泡：一个 DOM 元素 + 每帧跟随

气泡不是画在画布上的，而是一个绝对定位的 DOM 元素 `#speech`：

- 用像素风边框 + `::before/::after` 两个三角形拼出**向下的气泡尾巴**；
- 位置由小人头顶的命中框换算而来，横向会自动避让左右边缘（不会超出屏幕）；
- 记下当前是"谁"在说话（`speechKey`），然后在封面动画循环里每帧调用 `followSpeech()`
  重新定位——所以拖他的时候气泡会跟着走，人走开了气泡会自动收起。

### 4. 事件绑定

- `pointerdown` 绑在 `#screen-hero` 上（画布被上方文案层盖着，绑在画布上收不到事件）；
- `pointermove` / `pointerup` 绑在 `window` 上，这样拖到画面以外再松手也能正确收尾；
- 统一用 Pointer Events，鼠标和触屏都生效；
- 点按钮（START 等）不会误触发拖动：命中目标若是 `button / a / input` 就直接忽略。

## 四、可调参数

都在 `template.html` 第 4b 节的开头：

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `HERO_DRAG_T` | `4` | 位移超过几像素算"拖动"，小于此值算"点击" |
| `setTimeout(hideSpeech, 3400)` | 3400 | 气泡停留毫秒数 |
| `heroOff` 的 clamp 范围 | `-20 ~ W+20` | 拖动时小人的活动范围（画布像素） |
| `speech` 的 `max-width` | `min(300px,60vw)` | 气泡最大宽度，长台词会自动换行 |

样式在 `template.html` 顶部 CSS 的 `/* ---------- hero 小人互动（新增） ---------- */` 区块，
气泡配色直接复用全局变量（`--paper` / `--ink` / `--gold`），换主题色时会跟着变。

## 五、想继续扩展

**给某个动作加一句专属台词**：在 `content/03-lawn.json` 的 `lawn.byAct` 里加一条键值对即可，
不用改代码。

**增加新的动作类型**（例如"弹吉他"）：
1. 打开 `template.html` 搜 `else if(act === 'wave')`，照着写一段 `else if(act === 'guitar')` 的画法；
2. 在 `drawLawn` 的 `sets` 里把某个小人的 `acts` 换成 `'guitar'`；
3. 在 `content/03-lawn.json` 的 `lawn.byAct` 里给 `guitar` 配台词（可选）。

**让小人拖动后"掉回地面"**：在 `onHeroUp()` 里给 `heroOff[序号].dy` 做一个简单的
上抛/回落动画即可（新增一个轻量 tween），但目前刻意没做——因为投屏场景下
"拖完就稳定停着"更好控制。

**让气泡内容支持长按显示多条**：可以给 `heroPick` 里的每个小人配一个台词游标，
单击循环往下说，而不是每次随机。改动点在 `speechLine()`。

## 六、已知边界

- **走动的那两个小人拖不动**：他们由动画循环按时间轴计算位置，强行拖走会让"来回走"逻辑和偏移量打架。当前策略是"能点、不能拖"，这是有意为之。
- **窗口尺寸变化会复位小人位置**：因为画布是按窗口宽度重新缩放的，偏移量是画布像素单位，不复位很容易被挤出画面。若你希望保留，可以把 `resize` 里的 `heroOff = {}` 改成按比例换算。
- **位置不持久化**：刷新页面后小人回到默认排布（只有"环节完成状态"会存到 localStorage）。想持久化的话，把 `heroOff` 一起写进 `STORE_KEY` 对应的对象即可。
- **触屏设备**：单指拖动有效；双指缩放页面会让坐标换算失效，松手后点一下即可恢复。
