# 03 · 内容修改指南

**改内容只需要动 `content/` 目录里的 JSON。** 改完保存 → 运行 `python build.py` → 打开 `dist/index.html`。

> JSON 语法三条铁律（比 JS 严格）：
> ① 不能写 `//` 注释；② 每项之间用逗号分隔，但**最后一项后面不能有逗号**；
> ③ 字符串必须用英文双引号 `"`，不能用单引号，也不能用中文引号。
> 改坏了不用慌：直接跑 `python build.py`，它会报出**哪个文件、第几行第几列**出错。

文件与配置的对应关系见 [../content/README.md](../content/README.md)。

## 一、改日期 / 场地 / 主办单位 → `00-event.json`

日期是全站唯一来源，**不要在各处手写年份**，用占位符：

```json
{
  "event": {
    "date": "2026-10-14",
    "time": "14:00",
    "venue": "主会场",
    "org": "黄河科技学院"
  }
}
```

`date` 支持 `2026-10-14` / `2026/10/14` / `2026.10.14` / `2026年10月14日`。
构建时以下占位符会被替换：

| 占位符 | 结果 | 典型出处 |
| --- | --- | --- |
| `{year}` | `2026` | `meta.htmlTitle`、`meta.subtitle`、`meta.hudLevel`、`boot.badge` |
| `{date}` | `2026.10.14` | `meta.meta`、`ui.end.plateLine` |
| `{dateIso}` | `2026-10-14` | 需要 ISO 格式的地方 |
| `{dateCn}` | `2026年10月14日` | 中文行文里 |
| `{weekday}` | `周三` | 按真实日历自动算 |
| `{month}` / `{day}` | `10` / `14` | 单独用到月、日的地方 |
| `{time}` / `{venue}` / `{org}` | `14:00` / `主会场` / `黄河科技学院` | 任意文案 |

在 `event` 里再加一个字符串字段（如 `"host": "校团委"`），就能在任意文案里写 `{host}`。
拼错的占位符不会被静默忽略，`build.py` 会提示"找不到对应字段"。

临时换日期不必改文件：

```bash
python build.py --date 2027-09-20
```

## 二、改协会名 / 大会名 → `01-meta.json` 的 `meta`

```json
"meta": {
  "htmlTitle": "人工智能创新协会 · {year} 全体大会",
  "eyebrow": "黄 河 科 技 学 院",
  "title": "人工智能创新协会",
  "subtitle": "{year} · 全体大会",
  "meta": "{date} · {venue} · 全体成员",
  "startBtn": "START",
  "startHint": "点击 START · 或按 Enter 开始",
  "hudName": "协会成员",
  "hudLevel": "Lv.{year} · 大会进度"

```

- `htmlTitle` 构建时会同步写进 `<title>`，浏览器标签页和分享卡片都是这个；
- `eyebrow` 里给每个字之间加空格（如 `黄 河 科 技 学 院`），像素字看起来更舒展；
- 换协会名后记得同步：`ui.end.orgLine`、`ui.about.origin`、`boot.line1`、`meta.title`。

## 三、改环节（流程板上的卡片） → `04-stages.json` 的 `stages`

`stages` 是数组，**数组里每一项就是一张卡片**。加一项就多一个环节，删一项就少一个。

```json
{
  "num": "09",
  "icon": "mic",
  "color": "#c8d4e6",
  "name": "自由交流",
  "tag": "随便聊聊 THE CHAT",
  "fig": "talk",
  "cloth": "#5f6f9c",
  "figCap": "自由交流",
  "desc": "环节都走完了，随便找人聊聊。",
  "list": ["找部长聊聊你想做的方向", "加一下部门群"],
  "chips": [["时长", "约 20 分钟"], ["形式", "自由交流"]]
}
```

| 字段 | 说明 |
| --- | --- |
| `num` | 两位字符串编号，同时用于「已完成」记录，**不要重复** |
| `icon` | 卡片图标，取值见下表 |
| `color` | 主题色：卡片侧边条、要点圆点 |
| `name` / `tag` | 卡片名称 / 卡片上的小标签 |
| `fig` | 详情弹窗里的人物类型，取值见下 |
| `cloth` / `figCap` | 人物衣服颜色 / 人物下方小字 |
| `desc` | 一句话介绍 |
| `list` | 要点列表 |
| `chips` | 信息块，`[标题, 内容]` 成对 |

### `icon` 可选值

| 值 | 图形 | 值 | 图形 |
| --- | --- | --- | --- |
| `bubble` | 对话气泡 | `snack` | 奶茶零食 |
| `mic` | 麦克风 | `dice` | 骰子 |
| `person` | 人物 | `building` | 建筑（启动页也在用）|
| `note` | 音符 | `chip` | 芯片 |
| `swords` | 交叉剑 | `clip` | 任务板 |
| `camera` | 相机 | `riddle` | 谜题 |
| `group` | 三个人 | `mouth` | 嘴巴 |
| `trophy` | 奖杯 | `garden` | 花树 |
| | | `reverse` | 双向箭头 |

想要新图标：在 `template.html` 里找 `ICONS = {`，照着已有图标写一个 16×16 的字符地图
（`o`=深色描边、`b`=主体色、`a`=点缀色，`.`=透明），再配一行 `pal` 配色即可。

### `fig` 可选值（详情弹窗里的人物动作）

`talk` 演讲·比划 / `speak` 发言 / `sing` 唱歌 / `dance` 跳舞 / `cup` 端杯子 /
`phone` 看手机 / `dice` 掷骰子 / `pose` 摆姿势 / `group` 三个人一起

## 四、增删改「才艺展示」 → `stages` 里 `fullPage: true` 的那一项

```json
"fullPage": true,
"gallery": [
  { "name": "贺梦翔", "role": "唱歌", "kind": "sing", "cloth": "#e7a7c4", "hair": "#3c3452",
    "desc": "开场第一首由他先来。",
    "chips": [["顺序", "第 1 个节目"], ["形式", "独唱"]] }
]
```

- `kind` 取值：`sing` 唱歌 / `dance` 跳舞；
- `cloth` 衣服色、`hair` 发色（可选，不写就用默认深色）；
- **加一位同学**：复制一整段 `{ "name": ... }` 粘在后面，改内容和 `chips` 里的顺序号；
- 卡片编号（`01`、`02`…）与"第 N 个节目"是自动生成的，不用手改编号；
- 但 `stages` 里对应环节的 `list` 和 `desc` 里如果写了人名，记得同步。

## 五、改「趣味互动游戏」 → `stages` 里 `gamePage: true` 的那一项

每个游戏只需两件事：**玩法说明**（左栏） + **现场演示**（右栏，可放大）。

```json
{
  "id": "quiz",
  "name": "猜成语",
  "sub": "看表情猜谜底",
  "icon": "riddle",
  "desc": "一句话介绍玩法。",
  "steps": ["第一步…", "第二步…", "第三步…"],
  "chips": [["题量", "10 题"], ["形式", "举手抢答"]]
}
```

`id` 与演示组件的对应关系（写在 `template.html` 的 `buildPlay` 里）：

| id | 演示组件 | 用到的数据 |
| --- | --- | --- |
| `quiz` | 看 emoji 猜答案，可揭晓 / 切题 | `quiz` |
| `mouth` | 嘴上说一个数、手上比一个数，相同判失败 | 内置随机，无需数据 |
| `garden` | 抽一个"园"，列出里面有什么 | `gardens` |
| `reverse` | 发一条指令，揭晓相反动作 | `commands` |

三个题库都在 `05-games.json`：

```json
"quiz":     [{ "e": "🐔 ✈️ 🐕 🕺", "a": "鸡飞狗跳" }],
"gardens":  [{ "n": "动物园", "items": ["老虎", "长颈鹿", "孔雀"] }],
"commands": [["举左手", "举右手"]]
```

（`e`=表情提示、`a`=谜底；`commands` 前者是主持人说的，后者是正确动作。）

> 想加**第 5 个游戏**：`games` 里加一项即可（说明栏会自动出现）。
> 但右栏演示区必须先在 `template.html` 的 `buildPlay` 里加一个分支，
> 否则会退化成"反向指令"的演示区。详见第九节。

## 六、改封面小人的台词 → `03-lawn.json`

```json
"lawn": {
  "hint": "拖动小人换个位置 · 点一下他会说话",
  "lines": ["欢迎来到人工智能创新协会！", "今天奶茶管够。"],
  "byAct": {
    "code": ["这段代码马上就跑通了……"],
    "robot": ["参数再调小一点试试。"]
  }
}
```

- `hint` 留空则不显示封面底部提示；
- 点一下小人 = 从他的动作专属台词 + 通用台词池里随机抽一句；
- 连续点同一个人不会连续听到同一句；
- `byAct` 的键名（动作）对应：`code` 敲代码 / `robot` 调机器人 / `badminton` 打球 /
  `drone` 遥控无人机 / `book` 看书 / `coffee` 喝奶茶 / `phone` 看手机 /
  `wave` 打招呼 / `talk` 聊天 / `walk` 走动。

## 七、改各页面的标题、按钮、提示语 → `02-ui.json` 的 `ui`

`ui` 下面按页面分好了组：`quests`（流程板）、`show`（才艺展示）、`perf`（单人页）、
`about`（协会介绍）、`games`/`game`（游戏）、`end`（结语）、`modal`（弹窗）、
`zoom`（放大层）、`help`（操作说明）、`toast`（右下角提示）。

几个带占位符的字段，**`{xxx}` 会被自动替换**，不要手写具体数字：

| 写法 | 含义 |
| --- | --- |
| `"THE SHOW · 环节 {num}"` | `{num}` → 该环节的编号（如 `05`） |
| `"正在载入 {n} 个大会环节…"` | `{n}` → 环节总数 |
| `"{done} / {total} 环节已完成"` | `{done}` 已完成数、`{total}` 总数 |
| `"「{name}」已完成 ✓"` | `{name}` → 环节名称 |

所以**增删环节后，所有编号/总数都会自动跟着变**，不需要挨个改文案。
这五个是运行时占位符，构建时不会被替换，也不要手动改成数字。

`ui.help.keys` 是操作说明弹窗里的快捷键表，`[按键, 说明]` 成对：

```json
"keys": [["Enter", "开始 / 确认"], ["Esc", "关闭窗口 / 返回"]]
```

## 八、换会徽 / 换字体

**会徽**

1. 用新图覆盖 `assets/logo-src.png`（白底、正方形最好，1024×1024 起）；
2. 运行 `python prep_logo.py` —— 自动裁白边、加圆形透明蒙版、缩放到 400×400，
   输出 `assets/logo.png`；
3. 运行 `python build.py` 重新内联。

> 不想做圆形蒙版？直接用修图软件导出一张透明底的 `assets/logo.png`（400×400 左右）覆盖即可，
> 跳过第 2 步。没有 Pillow 时：`pip install pillow`。

**字体**

把新字体转成 `woff2`，覆盖 `assets/zpix.woff2`，再跑 `build.py`。
若字体名称不是 Zpix，还要改 `assets/style.css` 里的两处 `font-family:'Zpix'`
（`@font-face` 与 `body`）。

## 九、进阶：改配色与动效（`assets/style.css` + `template.html`）

样式已从 `template.html` 抽到 `assets/style.css`，`build.py` 会自动把它内联回产物。
文件顶部的 `:root` 集中了全部颜色变量：

```css
:root{
  --ink:#2b2f4a;      /* 主深色（描边、正文） */
  --paper:#fdf7ea;    /* 纸张底 */
  --gold:#f0cf83;     /* 金色点缀 */
  --green:#a9dd77;    /* 主按钮绿 */
  --px:3px;           /* 全局"像素厚度"，改大改小会影响所有描边 */
}
```

其它常用的调整点：

| 想改什么 | 位置 |
| --- | --- |
| 每个环节的主题色 | `content/04-stages.json` 里各环节的 `color` |
| 小人的衣服配色池 | `template.html` → `CROWD_COL`（`wear` 那行）|
| 撑起场景的随机种子（换成别的数字，城市/树/花会重新排布） | `drawScene` 里 `makeRng(20260611)` |
| 云的数量与速度 | `drawClouds` 里 `var n = 7;` 与 `var spd = ...` |
| 进度保存的键名 | `STORE_KEY` |
| 气泡停留时长 | `showSpeech` 里 `setTimeout(hideSpeech, 3400)` |
| 判定"这是拖动而不是点击"的像素阈值 | `HERO_DRAG_T = 4` |
| 断点、字号、间距 | `assets/style.css` 底部 `@media` 段 |

## 十、改动检查清单

改完内容后，花一分钟过一遍：

- [ ] 每个环节的 `num` 没有重复，且是两位字符串（`"01"` 而不是 `1`）；
- [ ] `chips` 里每一项都是 `["标题", "内容"]` 两个元素；
- [ ] 新增的环节如果要有整页，别忘了加 `aboutPage` / `fullPage` / `gamePage` 开关，
      并且**同一类开关全站只能出现一次**（代码是按"第一个带该开关的环节"来找的）；
- [ ] 日期只写在 `00-event.json` 里，其它地方都是 `{year}` `{date}` 这类占位符；
- [ ] 跑 `python build.py` 没有 `[!]` 警告；
- [ ] 打开 `dist/index.html`，把流程板、环节弹窗、才艺展示、游戏页都点一遍，
      看有没有文字溢出或空卡片。
